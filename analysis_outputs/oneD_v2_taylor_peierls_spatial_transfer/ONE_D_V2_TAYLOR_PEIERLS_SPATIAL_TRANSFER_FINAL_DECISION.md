# Taylor/Peierls spatial-transfer experiment

## Scope

DBTT, 1100 K, seed 1008666, theta=0, tip-only, through 300 um. Cleavage, emission, and every non-Taylor/non-Peierls material field were held fixed. No memory term and no FEM/CZM calculation were used.

## Execution

The fully evaluated 513-row DBTT option pool was replayed with the spatial 1-D state model. All 513 reached 300 um uncensored and passed the first-onset-within-20-percent gate. Eight response-space representatives were transferred to PF. One compatible control was reused and seven missing cases were run with no more than two workers.

## Rank transfer and resistance

The robust pairwise-distance association from 1-D to 2-D is Pearson -0.161624, Spearman -0.179529; the control-distance rank association is -0.0714286. The largest 2-D state distance is 368.75.

All resistance values use V2 reload-separated pre-event onsets. Positive candidates: 0 of 8. The candidate range in DeltaK_reinit is -6.3436 to -6.32963 MPa sqrt(m).

## Decision

**TAYLOR PEIERLS REDISTRIBUTION ALONE INSUFFICIENT DESPITE 2D STATE DIVERSITY.** The conditional local/multiseed confirmation was not launched because no positive reload-separated candidate was found. Spatial diversity therefore does not establish toughening: within this fixed-field experiment, Taylor/Peierls redistribution alone is insufficient.

Native PF apparent resistance remains separate from the source-opening local-equivalent measure. The decomposition table records native, local, shielding, and radius changes without treating native KJ as remote applied K.
